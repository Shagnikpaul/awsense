## Learnings

* CloudWatch custom metrics can take a few minutes before datapoints appear.
* Lambda execution roles may require a short propagation period after IAM updates.
* Integration tests often fail first because of module-level initialization.
* `conftest.py` is useful for providing test-wide environment variables.
* Mocking dependencies allows testing handler behavior without hitting AWS services.
* Keeping infrastructure initialization out of module scope improves testability.
* CloudWatch dashboards can combine Lambda, DynamoDB, and custom application metrics.
