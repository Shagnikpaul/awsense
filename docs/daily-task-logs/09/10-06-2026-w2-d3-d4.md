## Learnings

* Lambda-native Python deployments require Linux-compatible compiled dependencies.
* FAISS binaries generated on Windows are incompatible with AWS Lambda runtime.
* Native packages like:

  * `faiss`
  * `numpy`
  * `pydantic_core`
  * `tokenizers`
    require ABI-compatible Linux builds.
* HuggingFace embedding APIs can fully replace local embedding model execution in serverless environments.
* Separating deployment dependencies into a dedicated `python_packages/` directory keeps backend architecture cleaner.
* CDK deployment can work without Docker if dependencies are prebuilt externally for Linux.
* Runtime `sys.path` injection is useful for modular Lambda dependency loading.
* Real-time CloudWatch streaming via AWS CLI significantly improves Lambda debugging speed.
* API Gateway + Lambda deployment debugging becomes much easier once log streaming is set up.
* Retrieval and inference pipelines can remain fully decoupled and provider-agnostic.
* Serverless RAG systems require careful handling of native Python packages and runtime compatibility.
