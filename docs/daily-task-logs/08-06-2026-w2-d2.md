## Learnings

* Local FAISS retrieval can fully replace managed vector databases during early-stage development.
* SentenceTransformer initialization time is the major contributor to retrieval startup latency.
* Lambda warm starts are critical for ML-based serverless applications.
* RAG pipelines can remain provider-agnostic if retrieval and prompt construction are decoupled from inference.
* Groq APIs can serve as an effective temporary inference backend during AWS Bedrock access restrictions.
* Metadata mapping is essential for clean citation rendering in RAG applications.
* Small-to-medium vector stores are practical to bundle directly inside Lambda deployments.
* Embedding generation and retrieval can be handled entirely offline/local before deployment.
* Retrieval quality depends heavily on chunking strategy and source cleaning quality.
