 ## Learnings

 * Proper mocking prevents unit tests from calling real external APIs
 * GitHub Actions jobs do not share filesystem state automatically between stages
 * Artifacts are the correct way to transfer generated files between workflow jobs
 * Vite environment variables are injected only during build time
 * CDK asset paths must exactly match workflow artifact restore paths
 * Lambda packaging with `from_asset()` includes everything inside the target folder
 * `sentence-transformers` is needed only during vector generation and not during Lambda runtime
 * FAISS vector stores can be generated reliably inside GitHub Actions runners
 * GitHub Actions runners are capable of handling moderately sized embedding/index generation workflows
 * Pytest can accidentally collect tests from vendored dependency folders if not excluded
 * CDK bootstrap is safe to run repeatedly and only updates bootstrap infrastructure if required
