## Learnings
- CloudWatch custom metrics can take a short time before graph data appears.
- Module-level environment variable access can break tests during import.
- Integration tests should verify component interaction, not real AWS services.
- Mock ordering matters when stacking multiple `@patch` decorators.
- Vitest relies heavily on correct Vite configuration and alias resolution.
- React test environments can behave differently from application runtime builds.
- Frontend tests often require additional ESLint configuration for Vitest globals.
- Unit tests must evolve whenever handler dependencies or request contracts change.
