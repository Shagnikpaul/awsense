### Learnings

* AWS Bedrock throttling issues make local-first RAG pipelines a necessary fallback for development continuity
* FAISS + SentenceTransformer provides a fully functional RAG system without external dependency, suitable for Lambda MVPs
* Cold start cost in ML-heavy workloads is dominated by model loading, not vector search itself
* Stable Lambda design requires strict separation of:

  * retrieval layer (FAISS)
  * prompt construction
  * validation layer
  * response formatting
* Python package structure (`src/` imports) is critical when switching between script execution and module execution (`-m pytest`)

* Local simulation of Lambda using pytest is an effective way to validate cloud architecture before deployment
